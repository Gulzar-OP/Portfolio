Why does ensemble work?

🎯 Error diversity

Models alag-alag mistakes karein to combine karne par errors cancel ho sakte hain. Same mistake karne wale identical models se benefit kam.

📉 Bias–Variance

Bagging variance ghataata hai. Boosting bias ko aggressively ghataata hai. Stacking complementary strengths learn karta hai.
Expected prediction error ≈ Bias² + Variance + Irreducible noise

Important: Accuracy hi sab kuch nahi. Imbalanced data mein precision, recall, F1, ROC-AUC/PR-AUC dekho. Leakage-free validation ensemble ke liye compulsory hai.

Bootstrap mini example

Original D = [A, B, C, D, E]. Possible bootstrap samples:

D₁ = [A, C, C, D, E]
D₂ = [B, B, C, E, E]
D₃ = [A, A, B, D, E]
Har sample ka size = 5

Final prediction calculation

Classification: 5 trees say [Yes, Yes, No, Yes, No]
Yes votes = 3, No votes = 2 ⇒ Final = Yes
Regression: predictions [12, 10, 14, 11, 13]
ŷ = (12+10+14+11+13)/5 = 60/5 = 12

Why ≈ 63.2% unique observations?

Probability that a specific row is not selected in one draw = 1 − 1/n.
In n draws: P(not selected) = (1 − 1/n)ⁿ.
As n becomes large: (1 − 1/n)ⁿ ≈ e⁻¹ ≈ 0.368.
So selected at least once = 1 − 0.368 = 0.632 = 63.2%.
Remaining ≈ 36.8% are Out-of-Bag (OOB) for that tree.
OOB score: Har row ko un trees se predict karao jinke bootstrap sample mein wo row absent thi. In predictions ka error validation estimate deta hai—alag validation set ke bina.
Exam line: Bagging independent learners ko bootstrap samples par parallel train karke variance reduce karta hai; high-variance models such as decision trees ke saath especially effective hai.

2. Random Forest

Random Forest = Bagging of decision trees + random feature subset at every split. Data randomness trees ko different samples deta hai; feature randomness trees ki correlation ghataati hai.

Split impurity calculations

Gini(S) = 1 − Σ pᵢ²    |    Entropy(S) = −Σ pᵢ log₂(pᵢ)
Information Gain = Impurity(parent) − weighted impurity(children)
Example: Parent has 10 records: 6 Yes, 4 No.
Step 1 — parent Gini: 1 − (6/10)² − (4/10)² = 1 − .36 − .16 = 0.48.
Candidate split: Left = (4Y, 1N), Right = (2Y, 3N).
Step 2 — left: 1 − (4/5)² − (1/5)² = 1 − .64 − .04 = 0.32.
Step 3 — right: 1 − (2/5)² − (3/5)² = 1 − .16 − .36 = 0.48.
Step 4 — weighted child Gini: (5/10)(.32)+(5/10)(.48)=.16+.24=.40.
Gini reduction: .48 − .40 = .08. Higher reduction is preferred.

Key hyperparameters

ParameterMeaningEffect
n_estimatorsNumber of treesMore = stable but slower
max_featuresFeatures tried per splitLower = more diversity
max_depthTree depthControls overfitting
min_samples_leafMinimum rows in leafLarger = smoother model
class_weightClass penaltyHelps imbalance
Limitation: Large forest less interpretable, memory-heavy, aur very high-dimensional sparse text mein linear methods kabhi better. Feature importance may be biased toward high-cardinality features; permutation importance/SHAP safer.

3. Boosting & AdaBoost

Boosting sequentially weak learners banata hai. Har next learner previous mistakes par zyada focus karta hai. Final model weighted combination hota hai.

Learner 1
mistakes →
Learner 2
hard cases →
Learner 3
Σ αₜhₜ(x) →
Strong model

AdaBoost binary classification — full calculation

Weighted error εₜ = Σ wᵢ I(yᵢ ≠ hₜ(xᵢ))
Learner weight αₜ = ½ ln((1−εₜ)/εₜ)
Update: wᵢ ← wᵢ exp(−αₜ yᵢhₜ(xᵢ)), then normalize
Data: 4 samples, initial weights wᵢ = 1/4 = 0.25. Weak stump misclassifies only sample 4.
1Error ε₁ = weight of wrong samples = 0.25.
2α₁ = ½ ln((1−.25)/.25) = ½ ln(3) = 0.5 × 1.0986 = 0.5493.
3Correct point unnormalized weight = .25e−.5493 = .25(.5774) = .1443 each.
Wrong point = .25e+.5493 = .25(1.732) = .4330.
4Total Z = 3(.1443)+.4330=.8659. Normalize:
each correct = .1443/.8659 = .1667; wrong = .4330/.8659=.5000.
5Next learner sees the earlier wrong point with 50% total importance.
Final: H(x) = sign(Σ αₜhₜ(x)). Learner with ε<0.5 gets positive α. ε=0.5 ⇒ α=0 (random learner useless).

Advantages

Simple, powerful, minimal tuning; weak stumps can make nonlinear boundary.

Risks

Noisy labels/outliers ko repeatedly high weight mil sakta hai; sequential training parallelize karna harder.

4. Gradient Boosting (GBM)

Gradient Boosting har new tree ko previous model ke negative gradient / pseudo-residuals par fit karta hai. Regression with squared loss mein ye actual residual y−ŷ hota hai.
F₀(x) = argminc ΣL(yᵢ,c)
rᵢₘ = −[∂L(yᵢ,F(xᵢ))/∂F(xᵢ)]F=Fₘ₋₁
Fₘ(x)=Fₘ₋₁(x)+η·hₘ(x)

Regression numerical — all steps

Targets: y=[10,14,18], squared error, learning rate η=0.5.
1Initial constant F₀ = mean(y)=(10+14+18)/3=14.
Predictions = [14,14,14].
2Residuals r₁=y−F₀=[10−14,14−14,18−14]=[−4,0,4].
3Suppose Tree 1 predicts h₁=[−3,1,3] for the three points.
4Update F₁=F₀+0.5h₁:
[14,14,14]+.5[−3,1,3]=[12.5,14.5,15.5].
5New residuals = y−F₁ = [−2.5,−.5,2.5]. Errors became smaller. Next tree fits these residuals.

Classification idea

Binary classification mein model raw log-odds F(x) learn karta hai. Probability sigmoid se:

p(y=1|x)=1/(1+e−F(x))
If F=1.2: e⁻¹·²≈0.301 ⇒ p=1/(1+.301)=0.769

Shrinkage trade-off

Small learning rate η (e.g., .03–.1) + more trees usually better generalization. High η learns quickly but overshoot/overfit kar sakta hai. Early stopping validation loss ko watch karta hai.

Bagging vs GBM: Bagging trees independently data subsets par; GBM trees sequentially residual/gradient par. RF deep trees use kar sakta hai; GBM usually shallow trees. Bagging variance-focused, boosting bias-focused.

5. XGBoost: Extreme Gradient Boosting

XGBoost optimized gradient tree boosting hai: second-order gradients, regularized objective, sparsity handling, column subsampling, parallel split search, cache awareness, pruning and missing-value default directions.

Objective = Σᵢ L(yᵢ,ŷᵢ) + Σₖ Ω(fₖ)
Ω(f)=γT + ½λΣⱼwⱼ² + αΣⱼ|wⱼ|

T = leaves, wⱼ = leaf score, γ = new leaf penalty, λ = L2, α = L1.

Second-order approximation

Obj⁽ᵗ⁾ ≈ Σᵢ[gᵢfₜ(xᵢ)+½hᵢfₜ(xᵢ)²]+Ω(fₜ)
gᵢ=∂L/∂ŷ; hᵢ=∂²L/∂ŷ²

Leaf weight and score — solved

w* = −G/(H+λ)    ;    Leaf contribution = −½ G²/(H+λ)
where G=Σgᵢ, H=Σhᵢ
Suppose one leaf: gradients g=[−1.2,−0.8,0.4], Hessians h=[1,1,1], λ=1.
G=−1.2−.8+.4=−1.6; H=1+1+1=3.
w*=−(−1.6)/(3+1)=1.6/4=0.4.
Score reduction magnitude = ½(−1.6)²/(3+1)=.5×2.56/4=0.32.

Split gain — solved

Gain = ½[Gᴸ²/(Hᴸ+λ)+Gᴿ²/(Hᴿ+λ)−G²/(H+λ)]−γ
Let Gᴸ=−2,Hᴸ=2; Gᴿ=.4,Hᴿ=1; λ=1, γ=.1; parent G=−1.6,H=3.
Left term = 4/3=1.3333; Right=.16/2=.08; Parent=2.56/4=.64.
Gain=.5(1.3333+.08−.64)−.1=.5(.7733)−.1=.3867−.1=.2867.
Gain positive ⇒ split useful.
Missing values: Training during each split checks whether missing rows left or right bhejne se best gain milta hai. That branch becomes default direction.

Regularization intuition

γ (gamma)

Minimum gain required to make a split. High γ = fewer branches.

λ (L2)

Large leaf weights punish karta hai; smooth shrinkage.

α (L1)

Some leaf weights exactly zero; sparsity encourage.

Optimization toolbox

  • learning_rate: 0.03–0.2 start; lower with more trees.
  • max_depth/min_child_weight: model complexity constrain.
  • subsample: rows fraction; overfitting reduce.
  • colsample_bytree: features fraction; diversity.
  • early_stopping_rounds: best validation iteration choose.
  • scale_pos_weight: negative/positive ratio for imbalance (starting heuristic).
# Leakage-safe conceptual workflow 1. Split train / validation / test (stratify for classification) 2. Fit preprocessing ONLY on train 3. Tune using validation or cross-validation 4. Use early stopping on validation metric 5. Lock configuration; evaluate once on untouched test 6. Explain with feature importance + SHAP; check subgroup errors
Do not: scaler/encoder poore dataset par fit, test set se tuning, ID columns ko features banana, accuracy-only reporting, time-series ko random shuffle, or probability threshold blindly .5 rakhna.

6. LightGBM & CatBoost

LightGBM

Histogram-based boosting continuous values ko bins mein convert karta hai. Tree leaf-wise (best-first) grow hota hai, level-wise nahi; same leaves mein loss faster reduce, but small data par overfit risk.

  • GOSS: large-gradient records keep; small-gradient records sample, reweight.
  • EFB: mutually exclusive sparse features bundle to reduce dimensions.
  • Control: num_leaves, max_depth, min_data_in_leaf.

CatBoost

Categorical features ko native handle karta hai. Naive target encoding leakage karta hai; CatBoost ordered target statistics use karta hai.

Ordered encoding example: category=Kolkata records chronological permutation outcomes [1,0,1]. Prior mean=.5, smoothing a=1.
For 1st occurrence: no earlier outcomes ⇒ (.5×1)/(0+1)=.5.
For 2nd: earlier sum=1,count=1 ⇒ (1+.5)/(1+1)=.75.
For 3rd: earlier sum=1,count=2 ⇒ (1+.5)/(2+1)=.50.
Current row's target never enters its own encoding ⇒ leakage controlled.

Manual category preprocessing often neededNative categorical support existsOrdered target statistics

Leakage-safe 5-fold method

  1. Training data ko 5 folds mein split.
  2. Fold k ke liye model remaining 4 folds par train, kth fold par predict.
  3. All holdout predictions join ⇒ full-length OOF column.
  4. Har base model ke liye repeat.
  5. Meta-model OOF prediction matrix Z par train.
  6. Test prediction: each fold-trained model average; meta-model ko feed.
Meta calculation: Logistic meta-model z = −1 + 1.2pRF + .8pSVM + 1.5pXGB.
For [.70,.60,.80]: z=−1+1.2(.7)+.8(.6)+1.5(.8)
=−1+.84+.48+1.20=1.52.
p=1/(1+e⁻¹·⁵²); e⁻¹·⁵²≈.219 ⇒ p=1/1.219=.820.

Blending

Single holdout set par base predictions bana kar meta-model fit. Simple/faster, but meta-training data kam aur result split-sensitive.

StackingBlending

5-mark answer ending: Stacking is useful when models make complementary errors. Meta-learner should usually be simple and regularized; otherwise it can overfit correlated base predictions.

Mean-centering

Some users always rate high/low. User mean remove karna preference shape compare karne mein help.

U₁ known ratings [5,4,1], mean μ₁=(5+4+1)/3=3.33.

Similarity

Cosine(a,b) = (a·b)/(||a|| ||b||)
Pearson(u,v)= Σ(rᵤᵢ−r̄ᵤ)(rᵥᵢ−r̄ᵥ) / [√Σ(rᵤᵢ−r̄ᵤ)² √Σ(rᵥᵢ−r̄ᵥ)²]

cos=42/(6.481×6.708)=42/43.474=0.966 (very similar).

Sparsity = 1 − observed ratings/(users × items)

3. Collaborative Filtering (CF)

User-based CF

Target user ke similar users find → unke ratings se missing rating predict.

r̂ᵤᵢ = r̄ᵤ + [Σᵥ sim(u,v)(rᵥᵢ−r̄ᵥ)] / [Σᵥ |sim(u,v)|]
Predict U's Movie X rating. U mean=3.5.
Neighbor V: sim=.8, mean=3, rates X=5 ⇒ deviation=2.
Neighbor W: sim=.4, mean=4, rates X=3 ⇒ deviation=−1.
Weighted deviation numerator=.8(2)+.4(−1)=1.6−.4=1.2.
Denominator=|.8|+|.4|=1.2.
r̂=3.5+1.2/1.2=4.5.

Item-based CF

User similarities ki jagah items ke co-rating patterns. Large commerce systems mein item relations user relations se more stable ho sakte hain.

r̂ᵤᵢ = Σⱼ sim(i,j)·rᵤⱼ / Σⱼ |sim(i,j)|
User rated item A=5, B=3. sim(C,A)=.9, sim(C,B)=.5.
Predict C = [.9(5)+.5(3)]/(.9+.5)=(4.5+1.5)/1.4
=6/1.4=4.286.

Cold start & solutions

1. Clustering Social Network Graphs

Modularity

Observed within-community edges ko random graph under same degrees se expected edges ke against compare karta hai.

Q = (1/2m) Σᵢⱼ [Aᵢⱼ − (kᵢkⱼ/2m)] δ(cᵢ,cⱼ)
Equivalent per community: Q=Σc[l꜀/m − (d꜀/2m)²]
Two-community example: total edges m=8.
Community 1 internal edges l₁=3, sum of node degrees d₁=7.
Community 2 internal edges l₂=4, degree sum d₂=9. (7+9=2m=16)
Q₁=3/8−(7/16)²=.375−.1914=.1836.
Q₂=4/8−(9/16)²=.5−.3164=.1836.
Total Q=.1836+.1836=.3672. Positive indicates more internal structure than null model.

Louvain algorithm

  1. Start: every node its own community.
  2. Move each node to neighboring community giving largest positive ΔQ.
  3. Repeat until no improvement.
  4. Collapse each community into super-node; edge weights sum.
  5. Repeat phases hierarchically.

Spectral clustering idea

Adjacency A, degree D, Laplacian L=D−A
Normalized Lsym=I−D⁻¹ᐟ²AD⁻¹ᐟ²

Small eigenvectors graph ki low-frequency structure capture karte hain; rows ko embedding ki tarah k-means se cluster.

Resolution limit: Modularity optimization chhoti real communities ko merge kar sakta hai. Ek single “best community” objective universal nahi.

2. Graph Partitioning

Goal: vertices ko balanced groups mein divide karna while cross-group edges (cut) minimize.

Cut(S,T)=Σᵢ∈S,ⱼ∈T wᵢⱼ
RatioCut = Cut(S,T)(1/|S| + 1/|T|)
Normalized Cut = Cut(S,T)/vol(S) + Cut(S,T)/vol(T)
Example: Partition S has |S|=3, T has |T|=2. Cross edges weights [1,2] ⇒ Cut=3.
RatioCut=3(1/3+1/2)=3(2/6+3/6)=3×5/6=2.5.
If vol(S)=8, vol(T)=6: Ncut=3/8+3/6=.375+.5=.875.

Girvan–Newman

Communities ke beech “bridge” edges shortest paths par frequently aate hain. Edge betweenness:

Cᴮ(e)=Σₛ≠ₜ σₛₜ(e)/σₛₜ
  1. Every edge betweenness compute.
  2. Highest betweenness edge remove.
  3. Recompute (important!).
  4. Graph breaks into components; choose partition by modularity.

Kernighan–Lin intuition

Initial two-way partition se start; nodes swap karke cut reduction gain compute; best cumulative swap sequence apply. Balanced partitions ke liye.

3. Finding Overlapping Communities

Real user simultaneously “college”, “coding”, “family”, “sports” groups ka member ho sakta hai. Hard clustering one label only; overlapping clustering multiple memberships.

Clique Percolation Method (CPM)

k-clique = fully connected k nodes. Two k-cliques adjacent if they share k−1 nodes. Chain of adjacent cliques = community; node can occur in multiple chains.

k=3 example: triangles C₁={A,B,C}, C₂={B,C,D}, C₃={D,E,F}.
C₁ and C₂ share {B,C}: k−1=2 ⇒ adjacent, same community.
C₂ and C₃ share only {D}: 1<2 ⇒ not adjacent.
Communities: {A,B,C,D} and {D,E,F}; D overlaps depending on clique membership/components.

Link clustering

Nodes nahi, edges cluster. Node ke incident edges different edge communities mein ho sakte ⇒ naturally overlap.

Neighborhood Jaccard similarity

J(A,B)=|N(A)∩N(B)| / |N(A)∪N(B)|
N(A)={B,C,D,E}; N(B)={A,C,D}. Excluding endpoints if chosen convention: shared={C,D}=2, union={A,B,C,D,E}=5 ⇒ J=2/5=.4.
Evaluation: Ground truth groups may be incomplete. Use overlapping NMI/F1, conductance, stability, and domain usefulness—not modularity alone.

1. Markov Random Fields (MRF)

Undirected model; direction unclear/symmetric relations, e.g. neighboring pixels, spatial labels, social influence.

P(X=x)= (1/Z) ∏꜀ ψ꜀(x꜀) = (1/Z)e−E(x)
Z=Σₓ ∏꜀ψ꜀(x꜀) = partition function

Image denoising energy example

E(x)=Σᵢ Dᵢ(xᵢ)+βΣ(i,j) I(xᵢ≠xⱼ)

Dᵢ = observed pixel se disagreement cost; second term neighboring predicted labels disagree karne ka penalty.

Two pixels: observed y=[0,1]. Candidate labels x=[0,0]. Unary mismatch cost: D₁=0, D₂=1. Pairwise disagreement=0. β=.7.
E([0,0])=0+1+.7(0)=1.
Candidate x=[0,1]: unary=0+0; disagreement=1 ⇒ E=.7.
Because lower energy higher probability, [0,1] preferred (for β=.7).
If β=2: E([0,0])=1, E([0,1])=2 ⇒ smoothing prefers [0,0].

Given its neighbors N(i), node Xᵢ is independent of all non-neighbor nodes: Xᵢ ⟂ XV\({i}∪N(i)) | XN(i).

2. Hidden Markov Model (HMM)

Hidden state qₜ directly visible nahi; observation Oₜ state se emit hota hai. First-order Markov: P(qₜ|q₁…qₜ₋₁)=P(qₜ|qₜ₋₁).

Parameters λ=(A,B,π)

Baum–Welch intuition

  1. E-step: forward-backward se expected transition/state counts.
  2. M-step: counts normalize karke A, B, π update.
  3. Likelihood stop improving tak repeat.
Numerical underflow: Long sequence probabilities extremely small. Scaling factors or log probabilities use karo. Viterbi in log space: multiplication → addition.

3. Review of Inference in Graphical Models

Queries

  • Marginal: P(X) — other variables sum out.
  • Conditional: P(X|E=e) — evidence observed.
  • MAP: most probable subset assignment.
  • MPE: most probable assignment of all unobserved variables.

Variable Elimination (exact)

Chain A→B→C; find P(C).
Joint=P(A)P(B|A)P(C|B).
P(C)=ΣA,BP(A)P(B|A)P(C|B).
First eliminate A: f(B)=ΣAP(A)P(B|A).
Then eliminate B: P(C)=ΣBf(B)P(C|B).
Order changes intermediate factor size, not final answer.

Numerical marginal

P(A=1)=.3. P(B=1|A=1)=.8, P(B=1|A=0)=.2.
P(B=1)=P(B=1|A=1)P(A=1)+P(B=1|A=0)P(A=0)
=.8(.3)+.2(.7)=.24+.14=.38.

1. Analyzing Biological Data

Sequence representation

One-hot DNA

k-mer example: sequence S=ACGAC, k=2.

Raw counts library size depend. CPM:

Gene count=500; sample total=10,000,000 reads.

Manual HMM forward

states = ["R", "S"]
pi = {"R": .6, "S": .4}
A = {"R": {"R": .7, "S": .3},
     "S": {"R": .4, "S": .6}}
B = {"R": {"U": .9, "N": .1},
     "S": {"U": .2, "N": .8}}
obs = ["U", "U"]

alpha = {s: pi[s] * B[s][obs[0]] for s in states}
for o in obs[1:]:
    alpha = {
        j: sum(alpha[i] * A[i][j] for i in states) * B[j][o]
        for j in states
    }
print(sum(alpha.values()))  # 0.411
